# 🤖 ROS2_Robotics_project

Welcome to our team's repository for the **Robot Programming** (*Programmazione di Robot C.I.*) course!

This repository serves as the central collaborative workspace for our group. We will use it to coordinate our work, share code, and track our progress throughout the semester. 

## 🎯 Purpose of this Repository
This repository is dedicated to two main activities:
1. **Ongoing Exercises:** Solving and sharing the practical assignments, tasks, and lab exercises provided by the professors during the course.
2. **Final Project:** Designing, implementing, and simulating our final robotic software project, which is required for the final exam evaluation.

## 🎓 Course Information
- **University:** Università degli Studi di Palermo (UNIPA)
- **Degree Program:** Bachelor's Degree in Robotics Engineering (*Ingegneria Robotica*)
- **Academic Year:** 2026/2027
- **Course Modules & Professors:**
  - *Module 1: Operating Systems for Robotics* (Prof. Rosario Sorbello)
  - *Module 2: Software Systems for Robotics* (Prof.ssa Valeria Seidita)

## 🛠️ Technologies & Tools
Based on the course syllabus, this repository will contain code and simulations utilizing the following tools and concepts:
- **Languages:** Python (mostly using Geany)
- **Frameworks:** ROS (Robot Operating System) & ROS 2
- **Simulators:** Webots / Gazebo
- **Key Concepts:** Node architecture, Topics, Services, Autonomous Agents, Knowledge Representation, and Reasoning.

## 📂 Repository Structure (Proposed)
- 📁 `exercises/` - Code and solutions for weekly assignments.
- 📁 `final_project/` - Source code, ROS/ROS 2 packages, and launch files for the final project.
